🚀 To Run Full System (Backend + Frontend)

Option 1: Quick Setup with PostgreSQL

  1. Download PostgreSQL from: https://www.postgresql.org/download/windows/
  2. Install PostgreSQL (remember your password!)
  3. Open SQL Shell (psql) and run:
    CREATE DATABASE slicemaster_db;
  4. Update password in SliceMaster-Backend/src/main/resources/application.yml
  5. Run backend:
    cd SliceMaster-Backend C:\maven\apache-maven-3.9.9\bin\mvn.cmd spring-boot:run
  6. Open frontend in browser
